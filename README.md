Política de Privacidad — LossTrack
1. Información general
Loosstrack es una aplicación destinada a ayudar a propietarios y administradores de
negocios a llevar un control de sus productos y ventas, analizar el comportamiento
comercial y obtener recomendaciones que puedan ayudarles a tomar decisiones
relacionadas con su inventario y estrategias de promoción.
Las funciones de la aplicación pueden incluir:
 Registro y consulta de ventas.
 Administración de productos.
 Análisis del comportamiento de las ventas.
 Identificación de productos con baja rotación.
 Identificación de productos con mayor movimiento.
 Generación de recomendaciones para promociones.
 Recomendaciones relacionadas con la reducción o ajuste de productos con baja
demanda.
 Visualización de estadísticas y tendencias de ventas.

2. Información que puede proporcionar el usuario
Dependiendo de las funciones utilizadas, LossTrack puede almacenar información
introducida directamente por el usuario.
Información del negocio
Durante la configuración inicial pueden solicitarse datos como:
 Nombre del negocio.
 Tipo de negocio.
 Nombre del propietario o administrador.
 Número aproximado de productos.
 Moneda utilizada.

Información de productos

El usuario puede registrar información relacionada con los productos comercializados,
incluyendo:
 Nombre del producto.
 Categoría.
 Precio.
 Cantidad disponible.
 Existencias.
 Movimientos de inventario.
 Información relacionada con las ventas.
Información de ventas
Para proporcionar las funciones de análisis, la aplicación puede utilizar información
registrada sobre las operaciones de venta, como:
 Producto vendido.
 Cantidad vendida.
 Precio de venta.
 Fecha de la operación.
 Historial de ventas.
 Frecuencia de venta.
La información exacta recopilada dependerá de las funciones disponibles en la versión
utilizada de la aplicación.

3. Uso de la información
La información proporcionada por el usuario se utiliza exclusivamente para proporcionar y
mejorar las funciones de LossTrack.
Entre sus principales usos se encuentran:
 Registrar y consultar las ventas.
 Mantener información sobre los productos.
 Calcular estadísticas de ventas.
 Analizar la frecuencia con la que se venden determinados productos.
 Detectar productos con baja rotación.
 Identificar cambios en el comportamiento de las ventas.

 Generar recomendaciones relacionadas con promociones.
 Generar sugerencias relacionadas con la reducción o ajuste de productos con baja
demanda.
 Mostrar información y estadísticas que faciliten el análisis del negocio.

4. Análisis de información
LossTrack puede procesar la información registrada por el usuario para identificar
patrones y tendencias relacionados con las ventas.
Por ejemplo, la aplicación puede determinar que un producto presenta una baja
frecuencia de venta durante un determinado periodo y, a partir de esa información,
mostrar una recomendación relacionada con una posible promoción o reducción de
existencias.
Los análisis y recomendaciones se generan utilizando la información disponible en la
aplicación.
Las recomendaciones proporcionadas por LossTrack son únicamente herramientas
de apoyo y no constituyen asesoramiento financiero, contable, comercial o
profesional.
El usuario es responsable de evaluar las recomendaciones antes de tomar decisiones
relacionadas con su negocio.

5. Recomendaciones de promociones
Cuando los datos disponibles lo permiten, LossTrack puede generar sugerencias
relacionadas con posibles promociones.
Estas sugerencias pueden considerar factores como:
 Frecuencia de venta.
 Cantidad de unidades vendidas.
 Periodos de baja demanda.
 Historial de movimiento de determinados productos.
Las recomendaciones no garantizan un incremento en las ventas ni un determinado
resultado económico.

6. Recomendaciones sobre productos de baja demanda

La aplicación puede identificar productos que presentan un movimiento reducido dentro
del periodo analizado.
A partir de esta información puede mostrar sugerencias como:
 Considerar una reducción de existencias.
 Evaluar una promoción.
 Revisar la cantidad de productos adquiridos.
 Analizar si el producto continúa siendo necesario para el negocio.
Estas recomendaciones son generadas automáticamente a partir de los datos registrados
y no representan una orden o instrucción para modificar el inventario.

7. Almacenamiento de los datos
Según el funcionamiento actual de LossTrack, los datos introducidos por el usuario se
almacenan localmente en el dispositivo.
Esto puede incluir:
 Información del negocio.
 Productos.
 Inventario.
 Registros de ventas.
 Estadísticas.
 Información utilizada para generar análisis y recomendaciones.
La aplicación mostrará al usuario cualquier cambio futuro que implique el envío o
almacenamiento de información en servidores externos.

8. Datos almacenados localmente
El almacenamiento local significa que la información utilizada por la aplicación permanece
en el dispositivo donde se utiliza LossTrack.
Por esta razón, el usuario debe mantener protegido su dispositivo mediante las medidas
de seguridad disponibles, como:
 Contraseña.
 PIN.
 Bloqueo de pantalla.
 Sistemas de autenticación disponibles en el dispositivo.

LossTrack no puede garantizar la seguridad de un dispositivo que haya sido
comprometido, perdido, robado o utilizado por personas no autorizadas.

9. Compartición de información
LossTrack no vende, alquila ni comercializa la información introducida por los
usuarios.
Mientras la aplicación utilice únicamente almacenamiento local, los datos registrados no
serán enviados a terceros para fines publicitarios o comerciales.
Si en el futuro se incorporan servicios que requieran transmitir información fuera del
dispositivo, esta Política de Privacidad será actualizada para explicar:
 Qué información se transmite.
 Con qué finalidad.
 Qué terceros pueden recibirla.
 Durante cuánto tiempo puede conservarse.
 Qué opciones tiene el usuario respecto de dicha información.

10. Servicios de terceros
La versión actual de la aplicación debe identificar cualquier servicio externo que tenga
acceso a información del usuario.
Si se incorporan posteriormente servicios como:
 Almacenamiento en la nube.
 Sistemas de análisis.
 Servicios de autenticación.
 Servicios de respaldo.
 Servicios de publicidad.
se informará al usuario sobre su utilización y sobre los datos que puedan ser procesados
por dichos servicios.

11. Datos personales de clientes y empleados
LossTrack está diseñada principalmente para administrar información comercial y de
inventario.

El usuario debe evitar introducir información personal de clientes, empleados u otras
personas cuando dicha información no sea necesaria para utilizar las funciones de la
aplicación.
Si una futura función permite almacenar datos personales de terceros, se deberá
proporcionar información específica sobre el tratamiento de dichos datos.

12. Seguridad
Se aplican medidas razonables para proteger la información utilizada por la aplicación
frente a accesos no autorizados, pérdida o alteración.
Sin embargo, ningún sistema de almacenamiento puede garantizar una seguridad
absoluta.
El usuario también es responsable de proteger el dispositivo donde utiliza LossTrack y de
evitar que personas no autorizadas tengan acceso a la aplicación.

13. Conservación de la información
Los datos pueden permanecer almacenados mientras sean necesarios para proporcionar
las funciones de LossTrack o hasta que el usuario decida eliminarlos mediante las
opciones disponibles.
El periodo de conservación puede depender de las características de almacenamiento y
de las acciones realizadas por el usuario.

14. Eliminación de datos
El usuario puede eliminar la información almacenada por la aplicación mediante las
funciones de administración y eliminación disponibles.
Dependiendo del sistema operativo y de la versión de la aplicación, también puede ser
posible eliminar los datos mediante las opciones de almacenamiento del dispositivo.
La eliminación de la aplicación puede provocar la pérdida de información
almacenada localmente que no haya sido respaldada.

15. Menores de edad
LossTrack está destinada principalmente a propietarios, administradores y responsables
de negocios.
La aplicación no está diseñada para recopilar deliberadamente información personal de
menores de edad.

Si se detecta que se ha proporcionado información personal de un menor sin la
autorización correspondiente, podrá solicitarse su eliminación.

16. Cambios en la Política de Privacidad
Esta Política de Privacidad puede modificarse cuando se incorporen nuevas funciones,
tecnologías o métodos de almacenamiento.
Cuando se realicen cambios importantes, se actualizará la fecha indicada al principio de
esta política y, cuando corresponda, se informará al usuario dentro de la aplicación.

17. Aceptación de la política
Al utilizar LossTrack, el usuario reconoce haber leído esta Política de Privacidad y
comprender cómo se utiliza la información proporcionada para el funcionamiento de la
aplicación.
El uso de la aplicación continúa sujeto a las condiciones y funcionalidades disponibles en
cada versión.
